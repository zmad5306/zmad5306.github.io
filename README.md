# Personal Site (Jekyll + Tailwind + GitHub Pages)

My personal site and blog. Jekyll 4 with a Tailwind CSS build step, deployed to GitHub Pages via GitHub Actions (`.github/workflows/pages.yml`).

## Prerequisites

- Ruby 3.x (`brew install ruby` on macOS) and Bundler
- Node.js 20+

## Setup

```sh
bundle install
npm install
```

## Run locally

```sh
npm run build:css          # or `npm run watch:css` in a second terminal
bundle exec jekyll serve --livereload
# open http://127.0.0.1:4000
```

Notes:

- `assets/css/main.css` is generated by Tailwind and gitignored — run the CSS build before Jekyll.
- Default build skips future-dated posts; add `--future` to include them.
- Dark mode is the default; the header toggle persists your choice in localStorage.
- Fonts are self-hosted under `assets/fonts/` (latin subsets, variable weight).
